# Personal Expense Tracker

A web-based Personal Expense Tracker developed using Python, Flask, HTML, CSS, JavaScript, and SQLite.

## About the Project
The Personal Expense Tracker helps users manage their personal finances by recording income and expenses in one place.

## Features
- User Registration and Login
- Secure User-Based Data Management
- Add Income
- Add Expenses
- View Transactions
- Financial Reports
- Dashboard with Income, Expense and Balance Summary
- SQLite Database Integration

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Framework:** Flask
- **Database:** SQLite
- **Code Editor:** Visual Studio Code

## Installation and Setup

1. Clone the repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Open the project folder.

3. Create a virtual environment:
   `python -m venv venv`

4. Activate the environment (Windows):
   `venv\Scripts\activate`

5. Install dependencies:
   `pip install -r requirements.txt`

6. Run the application:
   `python app.py`

7. Open your browser and visit:
   `https://personal-expense-tracker-ahbw.onrender.com'

This project was developed to practice Python web development, database management, and frontend design.
